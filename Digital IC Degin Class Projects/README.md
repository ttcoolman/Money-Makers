# USC Digital Design & Computer Systems Projects

This repository contains a collection of laboratory assignments and projects completed for **EE 354 – Introduction to Digital Circuits** and **EE 457 – Computer Systems** at the **University of Southern California (USC)**.

Rather than organizing the repository by lab number, each project is named after the digital system or concept it implements, making the repository easier to navigate and more representative of the engineering skills demonstrated.

---

## Courses

### EE 354 – Introduction to Digital Circuits

EE 354 introduces the fundamentals of digital logic design and hardware implementation using Verilog HDL. Projects focus on designing, simulating, and verifying digital circuits while building a foundation in modern digital systems.

**Concepts Covered**

* Boolean Algebra
* Combinational Logic
* Sequential Logic
* Multiplexers and Decoders
* Arithmetic Circuits
* Flip-Flops and Registers
* Counters
* Shift Registers
* Finite State Machines (FSMs)
* Hardware Simulation
* Verilog HDL Design

---

### EE 457 – Computer Systems

EE 457 expands on digital design concepts by exploring how complete computer systems are built from hardware components. Projects emphasize processor organization, memory systems, and computer architecture using Verilog.

**Concepts Covered**

* Processor Datapaths
* Control Units
* Instruction Set Architecture (ISA)
* Pipelining
* Hazard Detection
* Memory Hierarchy
* Cache Fundamentals
* Performance Analysis
* System-Level Hardware Design
