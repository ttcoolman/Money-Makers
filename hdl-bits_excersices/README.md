# HDLBits Solutions

A collection of my solutions to exercises from **HDLBits**, completed while learning digital logic design and Verilog HDL.

## About

This repository contains my implementations of HDLBits problems, covering fundamental and advanced digital design concepts. The goal of this repository is to document my progress, reinforce hardware design principles, and serve as a reference as I continue studying computer architecture, FPGA design, and processor implementation.

HDLBits is an online platform that provides hands-on Verilog exercises ranging from basic combinational logic to finite state machines and sequential circuits.

**HDLBits:** https://hdlbits.01xz.net/wiki/Main_Page

---

## Topics Covered

* Basic Verilog Syntax
* Combinational Logic
* Sequential Logic
* Latches and Flip-Flops
* Counters
* Shift Registers
* Multiplexers and Decoders
* Adders and Arithmetic Circuits
* Finite State Machines (FSMs)
* Memories
* Cellular Automata
* Simulation and Testbenches
