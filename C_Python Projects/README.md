### Lab 2 – Matrix Processing and File Operations

Implemented identical solutions in **C++** and **Python** for matrix processing.

#### Features
- Read two 10×10 matrices from text files
- Perform linear search
- Find repeated occurrences of the first matrix element
- Determine minimum and maximum values
- Matrix addition
- Matrix multiplication (implemented manually)
- Store Python results using Pickle serialization

#### Technologies
- C++
- Python
- NumPy
- Pickle

#### Concepts
- Object-Oriented Programming
- Nested loops
- File I/O
- Matrix algorithms
- Data serialization
